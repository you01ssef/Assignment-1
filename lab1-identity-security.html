01 / DESCRIPTION

Purpose and setup

This lab examines how a computer identifies itself on a network and reaches other devices. I will inspect my IP address, subnet mask, gateway, DNS server, and MAC address; test connectivity with ping and traceroute; and observe how ARP maps nearby IP addresses to MAC addresses.

02 / PROCEDURE AND NOTES

IP configuration

On Windows, use ipconfig and ipconfig /all. On macOS, use Network settings or ifconfig for interface details, route -n get default for the gateway, and scutil --dns for DNS servers.

What the mask does: it identifies which bits of an IP address describe the network and which identify a host. A device on the same subnet is reached locally; traffic to another subnet goes to the default gateway.

Useful administrator options: on Windows, ipconfig /all shows detailed settings, /release releases a DHCP lease, /renew requests one, and /flushdns clears the DNS resolver cache. Use ipconfig /renew to obtain a new DHCP configuration.

Only change network settings on a device and network where you have permission. Restore the original configuration when finished.

03 / PROCEDURE AND NOTES

Ping and routes

ping checks whether a target replies and reports round-trip time. TTL is a packet hop limit; the value shown in a reply is the remaining limit, not a measure of distance or proof of identity. A ping reply alone cannot establish that the expected computer sent it. Confirm the target address and, where needed, use authenticated services or another trusted identification method.

Use tracert www.kean.edu and tracert www.google.com on Windows, or traceroute on macOS. Repeating a trace can show route changes or load balancing. Asterisks may indicate a router that does not answer probes, not necessarily a broken route.

04 / PROCEDURE AND NOTES

ARP cache

Use arp -a to display local ARP entries. Each entry associates a local IPv4 address with a MAC address. After clearing an entry where permitted, new traffic to that neighbor can cause the entry to appear again. ARP does not resolve remote destinations to their final MAC address; the computer resolves the local next hop instead.

05 / RESULTS AND REPORT

Conclusion

IP settings determine where my computer belongs on the network and how it sends traffic beyond the local subnet. Ping and traceroute help observe reachability and route behavior. ARP shows the layer 2 address used for a local neighbor or gateway. Actual values depend on the computer and network used.
